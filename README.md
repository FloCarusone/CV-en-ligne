# CV en ligne — Florian Carusone

## Description

Ce projet consiste en la création d’un CV en ligne développé en HTML, CSS et JavaScript, dans le cadre de la formation d'informatique de gestion.
Le site présente mon parcours professionnel, mes compétences et mes informations personnelles sous forme d’une page web moderne et interactive.

---

## Fonctionnalités

- Structure HTML complète du CV
- Design CSS moderne et professionnel
- Photo de profil
- Traduction dynamique du site en :

  - Français
  - Anglais
  - Allemand

- Sélection de la langue directement via la section "Langues"
- Conservation des liens cliquables après traduction

---

- GitHub
